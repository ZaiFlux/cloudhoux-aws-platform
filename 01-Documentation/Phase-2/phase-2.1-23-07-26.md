# Phase 2.1 – Landing Page Development

**Date:** 2026-07-23

## Overview

This phase focused on setting up the foundation of the CloudHoux web application by creating the landing page and configuring Git to ignore unnecessary files.

## Tasks Completed

### 1. Created the Landing Page

- Created the `main.html` file as the primary entry point of the CloudHoux website.
- Created the `style.css` file to handle the styling and layout of the landing page.
- Established the initial project structure for future frontend development.

### 2. Configured Git Ignore

Created a `.gitignore` file to prevent unnecessary files and folders from being tracked by Git.

The following directory was excluded:

```gitignore
.vscode/
```

This ensures that Visual Studio Code workspace settings are not pushed to the GitHub repository, keeping the repository clean and consistent for all contributors.
